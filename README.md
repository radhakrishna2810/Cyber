# National Cyber Crime Reporting Portal — AI-first Redesign

A production-ready Next.js frontend foundation that reimagines the National Cyber Crime Reporting Portal as a premium, accessible, AI-powered government cybersecurity ecosystem.

## Delivered
- Full information architecture coverage for citizen, officer, police, admin, support, bank, and institutional journeys.
- AI-first reporting, evidence analysis, semantic search, risk scoring, duplicate detection, translation, voice reporting, and officer copilot concepts.
- WCAG AAA-oriented accessibility settings, keyboard focus states, reduced motion support, high contrast-ready tokens, and semantic sections.
- Enterprise design system foundations: typography scale, spacing, colors, elevation, radius, responsive cards, dashboards, timelines, and state patterns.
- Next.js, React, TypeScript, Tailwind CSS, PWA manifest, responsive layouts, and reusable data-driven components.

## Commands
```bash
npm run dev
npm run build
```
